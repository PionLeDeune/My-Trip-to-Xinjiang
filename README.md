# xinjiang-travel

轻量静态站点骨架，包含：

- index.html — 首页总览（小地图 + 酒店横向滚动 + 餐饮横向滚动 + 行程概述）
- map-detail.html — 景点独立详情页
- hotel-single.html — 酒店专题(Needs to GoLive)
- food-detail-xx.html — 餐饮专题(No needs to GoLive)
- css/global.css — 全局样式
- js/map.js, js/scroll.js, js/util.js — 基础交互脚本
- img/ — 图片资源占位目录
